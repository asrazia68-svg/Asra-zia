## 🚀 Featured Projects

### ⚡ [AI Social Media Agent](https://github.com/asrazia68-svg/social-media-ai-agent)
Multi-agent content generation system — dedicated AI agents handle strategy, market research, writing, and review to auto-generate platform-specific posts (Instagram, LinkedIn, Twitter, Facebook, TikTok) for a brand.
`Python` `Streamlit` `Multi-Agent Workflow`

### 📝 [DocuQuery AI — RAG System](https://github.com/asrazia68-svg/Rag_system)
A full-stack Retrieval-Augmented Generation app — upload PDF/TXT documents and chat with them. Uses HuggingFace embeddings, ChromaDB vector storage, and Groq's LLaMA 3.3 70B for fast, context-aware answers with conversational memory.
`Python` `LangChain` `Groq` `ChromaDB` `Streamlit`

### 🔫 [Weapon Detection System](https://github.com/asrazia68-svg/Weapon-Detection-system)
Real-time weapon detection using a custom-trained YOLOv8 model — works on both static images and live webcam feed, with an automatic audio alarm triggered on detection at a 60% confidence threshold. Built for security/surveillance use cases.
`YOLOv8` `OpenCV` `Python`

### 🛡️ [CyberSentinel AI](https://github.com/asrazia68-svg/Cybersential-ai)
AI-driven security assessment & SOC monitoring platform (Final Year Project) — a full-stack dashboard with 10 pages including vulnerability assessment, live alerts, SIEM-style event monitoring, and an AI analyst that generates incident analysis.
`FastAPI` `React` `Tailwind CSS` `SQLite`
